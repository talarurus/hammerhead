## Wording changes versus evaluation changes

SEC-001, FILE-001, FILE-002, GIT-001 and PROJ-001 change check/finding versions from 0.1.0 to 0.2.0 for corrected prose. GIT-002 stays at its existing 0.2.0; PROJ-002 stays at 0.1.0. This milestone makes **no evaluation changes**: regexes, match helpers, filename priority/exemptions, threshold comparisons, content eligibility, severity, confidence, class, rule IDs, line/path/ID inputs, finding multiplicity and redaction remain unchanged. GIT-001 changes only the prose in its evidence label; its category-based ID inputs are unchanged.

Finding identity and JSON field names/types stay intact. Active variant title expectations and reporter sample wording follow the new text. The four active v0.2 JSON status goldens use synthetic findings, not these detector strings, and need no regeneration. Historical `internal/reporter/testdata/v0.1` fixtures, provenance and release tag remain immutable. There is no claims catalog, resolver, explanation renderer, added detector, network call or credential validation.
